     - JS多逗号/花括号 — 检测 },, 和花括号不匹配（微信小程序兼容）

### 关键决策
- 每个工具只负责一件事
- git hook优先于手动脚本
- 统一 [OK] [FAIL] [WARN] 替代emoji
- REPO_ROOT硬编码避免 __file__ 解析

### hook已验证的6项检查
1. py_compile 编译检查
2. __pycache__/.pyc 清理
3. 空except检测
4. BOM头(EF BB BF)检测
5. 硬编码截断 [:d] 检测
6. UTF-8编码校验
7. JS多余逗号和花括号不匹配

### 设计教训
- 子进程内存只能从外部监控（memwatch模式）
- git reset HEAD 必须 --quiet 避免输出过长
- PowerShell && 在 -Command 模式不能直接用
- hook测试必须直接 python file.py --hook，不能走subprocess
