============================================================
  蔡引导音色克隆 - AutoDL 一键训练指南
============================================================

总花费: 约3-5元 | 总时间: 约30-60分钟

============================================================
第1步：注册AutoDL（30秒）
============================================================
1. 打开 https://www.autodl.com/register
2. 手机号注册，登录后充10块钱

============================================================
第2步：创建GPU实例（2分钟）
============================================================
1. 控制台 -> GPU云服务器
2. 选择镜像：PyTorch 2.x (CUDA 12.1)
3. GPU选择：RTX 4090（1.98元/时）或 RTX 3090（1.58元/时）
4. 数据盘选50GB，点击创建，等1分钟变运行中

============================================================
第3步：上传音频文件（1分钟）
============================================================
1. 点击JupyterLab -> 打开终端(Terminal)
2. 执行: mkdir -p /root/autodl-tmp/input_audio && cd /root/autodl-tmp
3. 把6个.aac文件拖拽上传到 input_audio 目录

============================================================
第4步：安装环境
============================================================
在终端复制粘贴运行：

cd /root/autodl-tmp &&
git clone https://github.com/RVC-Boss/GPT-SoVITS.git &&
cd GPT-SoVITS &&
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple &&
pip install openai-whisper -i https://pypi.tuna.tsinghua.edu.cn/simple &&
python tools/download_models.py &&
echo "环境安装完成"

============================================================
第5步：开始训练（一键，粘贴运行）
============================================================

python tools/train.py
  --train_data_dir /root/autodl-tmp/input_audio
  --output_dir /root/autodl-tmp/output_model
  --epochs 20
  --batch_size 2

============================================================
第6步：下载模型
============================================================
训练完成后下载3个文件到：
D:\AISleepGen_Optimized\voice_clone_model\
  - gpt_weights.ckpt
  - sovits_weights.pth
  - config.json

============================================================
第7步：测试+批量生成
============================================================
运行: py -3 D:\AISleepGen_Optimized\docs\batch_generate_cai_guides.py

全部搞定了。后续所有新引导语自动用蔡声音生成。
