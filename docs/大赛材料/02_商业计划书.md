### 模型详解

#### 1. 睡眠皮肤模型

从用户面部视频/可穿戴设备采集皮肤电信号，实时推断：
- 睡眠阶段（清醒/浅睡/深睡/REM）
- 心率变异性（HRV）趋势
- 自主神经活动水平

**与竞品差异**：大多数皮肤分析产品只做"肤质评分"，不做睡眠关联。AISleepGen 把皮肤电信号和认知状态做了桥接——你的皮肤在出汗/发红/发凉，模型会推断你的唤醒水平，并通知世界模型调整干预策略。

#### 2. 睡眠EDF模型

基于欧洲数据格式（EDF）标准，实现 AASM 国际睡眠分期准则的 AI 化：
- 输入：EEG/EOG/EMG 信号（标准 PSG 格式）
- 输出：30秒/帧的睡眠分期（W/N1/N2/N3/REM）
- 支持：单导联/多导联自适应

**为什么重要**：EDF 是睡眠医学的国际数据标准。有这个模型意味着 AISleepGen 可以和任何三甲医院睡眠中心的 PSG 数据对接——这是进入临床路径的技术前提。

#### 3. 睡眠整晚音频模型

整晚不间断音频分析，分层输出：
- 环境层：噪声事件（车声/雨声/邻居）→ 环境干扰评分
- 生理层：鼾声/呼吸/咳嗽 → 呼吸事件检测
- 行为层：翻身/起床/梦话 → 行为碎片化指标
- 情绪层：叹气/呻吟/深夜语音 → 情绪状态线索

**独有性**：竞品做鼾声检测的很多，但把整晚音频拆成四层输出并输入到世界模型做决策的，国内没有。

#### 4. 世界模型 v2.0（Digital Twin of Your Mind）

**做什么**：将前三层模型的输出（生理/音频/环境）融合为用户实时 8 维状态向量：
- 唤醒水平 │ 情绪极性 │ 认知负荷 │ 生理疲劳度
- 环境干扰 │ 干预敏感性 │ 时间上下文 │ 治疗阶段

**每次对话都在更新**——不需要用户填问卷。AI 自动感知你今天比昨天更焦虑，动态降低语速、延长呼气引导。

**突变动力学引擎**：当检测到状态陡变（HRV 骤升、语气哽咽），200ms 内切换干预模式。传统 AI 假设状态平缓转移——但凌晨 3 点的崩溃不是平缓的。

**8 专家会诊**：认知/情绪/生理/环境/行为/干预/学习/安全 8 路并行分析，不是简单投票，是基于当前状态权重的动态融合。

#### 大模型层：合理使用，不自欺欺人

最上层对话生成调用 DeepSeek API。这不是弱点——这是理性选择：
- 对话生成本身不是一个需要自训模型的问题（差异在决策逻辑）
- DeepSeek API 成本极低（¥0.05-0.15/次），支撑免费模式
- **任何大模型都可以换**——四层自研模型不变，底层 API 升级时只调 Prompt 映射层

### 四层模型的复合壁垒

| 层 | 自研 | 竞品状态 | 复制难度 |
|---|------|---------|---------|
| 皮肤模型 | ✅ 自研 | 无（仅肤质评分） | 6个月+数据 |
| EDF模型 | ✅ 自研 | 仅学术机构 | 8个月+临床数据 |

**真正的壁垒不是每一层单独看，而是四层串联后的闭环**——传感器→生理→认知→干预→复查→改善。竞品在一个维度上对标都吃力，四个维度的组合没有人做到。

### 隐私与合规

四层模型全部支持端侧推理，语音/生理数据不做云端留存：
- L1 结构化操作日志（审计追踪）
- L2 决策轨迹存档（每轮推理链）
- L3 输出合理性校验（自动检测不合理预测）
- GDPR 级被遗忘权 + 数据导出

## 十、技术路线：从"单智能体"到"对抗-协作双模型"

受《我的天才朋友》中莉拉与莱农终身智力纠缠的启发——最好的学习发生在两个势均力敌的个体互相充当对方的"判别器"。

AISleepGen 当前的世界模型是 8 位专家会诊后由一个 POMDP 求解器做统一决策。下一个架构升级方向：

### 双模型对抗-协作架构

- **模型 A（探索者）**：给出激进的干预方案，探索边界
- **模型 B（约束者）**：评审方案、指出漏洞、坚守安全
- 两者对抗若干轮后达成共识输出最终方案

这本质上是**对抗生成网络（GAN）在决策空间的迁移**——不是生成更真实的数据，而是生成更有效的干预策略。

### 自我博弈式的终身学习

每次对话结束后，两个模型会回顾自己的决策记录，识别"如果在那个时刻选了另一条路会怎样"——这是 AlphaGo 式自我博弈在睡眠教练场景的落地。

这个演进路径意味着：AISleepGen 会越用越聪明，但聪明的方向不是"更会聊天"，而是**更精准地识别何时说话、何时沉默、用什么节奏**。

### 为什么现在不做？
我们的原则：不要在数据还没跑起来的时候堆技术债。当前唯一优先是**积累 ISI 临床数据**——数据到了，双模型架构的学习信号自然就有了。顺序不能反。
