# 竞品分析：AI 驱动的失眠数字疗法赛道

## 一、赛道全景

失眠数字疗法（Digital Therapeutics for Insomnia）全球市场规模：
- 2025年约 $8.2B（MarketsandMarkets）
- 2030年预计 $18.5B（CAGR 17.6%）
- 中国失眠人口约 3 亿（中国睡眠研究会 2024），渗透率 <1%

## 二、主要竞品

### 国际竞品

| 竞品 | 融资/估值 | 核心技术路径 | 商业模式 | 优劣势 |
|------|-----------|-------------|---------|--------|
| **Sleepio** (Big Health) | $48M total | CBT-I 数字化课程 + 虚拟教练 | B2B（企业医保） | ✅ 临床证据最充分（7项RCT）❌ 非AI，纯规则驱动 |
| **Cerebra** (前称 Somryst) | Pear Therapeutics 收购后破产重组 | 处方数字疗法（FDA cleared） | 医保报销 | ✅ FDA 认证 ❌ Pear 破产暴露 DTx 商业变现难题 |
| **Calm** | $300M+（2020） | 冥想内容平台 | B2C 订阅 | ✅ 用户规模大 ❌ 非失眠专用，无临床闭环 |
| **Kip** (前称 Sleep Reset) | $12M seed | CBT-I + 1:1 教练 | B2C 高客单价 | ✅ 真人教练拉留存 ❌ AI 能力弱，依赖人力 |

## 三、AISleepGen 的差异化定位

| 维度 | 竞品共识 | AISleepGen 怎么做 |
|------|---------|-----------------|
| **自研模型层数** | 0-1层（皮肤或鼾声或问卷） | 4层（皮肤+EDF+音频+世界模型） |
| **皮肤 → 睡眠关联** | 无（只做肤质评分） | 皮肤电信号→唤醒水平→世界模型 |
| **临床数据标准** | 无 | EDF格式原生支持，可对接PSG |
| **整晚音频深度** | 单一鼾声检测 | 四层分析（环境/生理/行为/情绪） |
| **AI交互策略** | 规则引擎/课程播放 | 世界模型v2.0 + 8专家会诊 + 突变动力学 |
| **评估方式** | 问卷 + 硬件 | 自研4模型自动提取→无需用户手动填 |
| **干预闭环** | 开到药方不管 | 实时HRV生物反馈 + 动态调整 |
| **商业模型** | B2C 订阅 / B2B 医保 | 先 B2C 跑通临床证据 → B2B 进医院 |
| **数据隐私** | 云端明文 | 端侧处理 + 联邦学习 + L3 级审计 |

## 四、竞争优势排序（评委最可能问的）

1. **技术壁垒**：世界模型 v2.0 + 突变动力学 — 国内唯一
2. **临床意识**：ISI 结局追踪 — 竞品几乎都没有
3. **合规完备性**：L1/L2/L3 审计 + 被遗忘权 + 隐私设计 — 达医疗级
4. **成本结构**：基于 DeepSeek API，推理成本仅为 GPT-4 的 1/20
