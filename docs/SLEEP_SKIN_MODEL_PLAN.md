## 2026-04-24 晚规划 · 2026-04-25 开干

## 一、目标定义

**核心问题：** 睡眠质量和压力水平如何在面部皮肤上体现？

**三个递进目标：**
1. **关联分析**（基线）—— 哪些睡眠指标和哪些面部特征变化显著相关？
2. **状态推断**（进阶）—— 用照片推断昨晚/近期的睡眠恢复效率
3. **趋势预测**（高阶）—— 连续多天的睡眠模式如何影响皮肤趋势变化

**不做的事：**
- ❌ 不搞"皮肤年龄"估算（那是另一套东西，需要大量训练数据）
- ❌ 不做护肤品推荐（跟睡眠无关）
- ❌ 不声称能诊断皮肤疾病

## 三、技术方案（明天我做的）

### 阶段一：面部特征提取（使用预训练模型，不训练CNN）

用 **MediaPipe Face Mesh** 或 **OpenCV DNN** 提取每张照片的量化特征：

**直接测量的物理特征：**
- 眼袋面积比例（眼下区域 vs 全脸）
- 面部水肿指数（脸颊轮廓线的曲率变化）
- 肤色均匀度（局部色差方差）
- 眼部开合度（上下眼睑间距——反映疲劳程度）
- 嘴角角度（反映情绪状态）
- 眉间纹深度（额头区域纹理）
- 鼻唇沟深度

**输出：** 每张照片 → 7-10个数值特征向量

### 阶段二：关联分析

用你的睡眠数据做监督学习：

```
X = 面部特征向量（来自照片）
Y = 睡眠指标（睡眠时长/深睡比例/压力分）
```

方法：
1. **相关矩阵** —— 每个面部特征 vs 每个睡眠指标的 Pearson/Spearman 相关系数
2. **随机森林** —— 哪个面部特征对睡眠质量预测最重要（特征重要性排序）
3. **时间序列** —— 前后几天的睡眠如何影响今天的面部（延迟效应分析）

### 阶段三：可视化报告

输出一份交互式 HTML 报告：
- 热力图：面部特征 × 睡眠指标 的相关系数矩阵
- 时间轴：睡眠评分 vs 面部特征变化趋势（同一条时间线）
- 特征重要性：哪些面部特征最能反映睡眠质量
- 个人基线：你的"好睡眠脸" vs "差睡眠脸"对比

## 六、关键约束

1. **数据量警惕**：如果你只有14-30天的数据，关联分析结果仅供参考，不能下因果结论
2. **混杂变量**：模型会标记"可能存在其他影响因素（饮食/经期/过敏）"
3. **个体特异性**：这个模型只针对你个人数据训练，不可推广到其他人
4. **不替代医学**：不声称能诊断或治疗
